
# SR-19 — Centralised logging + anomaly alerting

## Requirement
The Vote Counting and Tabulation subsystem shall record significant security and operational events in structured logs,
protect those logs from loss or tampering, and generate alerts when activity matches defined suspicious patterns, 
so that incidents can be detected, investigated and attributed.
Significant events include failed login attempts, exclusion-action creation and decisions, tally updates and backup outcomes.


## Owner
Rosie

## Status
Implemented

## Security objective
The objective is to improve monitoring, accountability and incident investigation by creating consistent event records
and by alerting the team when activity exceeds defined thresholds. 
This supports the integrity and availability of the subsystem by shortening the time between a suspicious event and a response.


## Threats
- Brute-force login attempts
- Untraceable administrative actions
- Delayed incident detection
- Log loss or tampering
- Sensitive data in logs


## Priority
Medium

## Complexity
Low
