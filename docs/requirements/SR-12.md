
# SR-12 — Isolated tally store, immutable backups, IR runbook

## Requirement
The Vote Counting and Tabulation subsystem shall store tally data separately 
from other application data, restrict access to authorised administrative roles,
and support reliable backups to reduce the risk of unauthorised modification,data loss and service disruption.
The prototype uses Node.js, TypeScript, Express, SQLite and Jest. 
The existing database contains user accounts and exclusion-action records. 
SR-12 proposes a separate SQLite database file dedicated to tally records.

## Security objective
The objective is to protect the confidentiality, integrity and availability of tally data.

## Threats

- Database compromise
- Accidental deletion or corruption
- Backup failure
- Inconsistent recovery copies
- Excessive privileges
